# PENGU1N — Christmas 3D Scene

A Vite + Three.js landing page featuring the supplied Sketchfab penguin model. The penguin slowly turns automatically and can still be rotated by dragging; scroll to zoom. The background forest is a lightweight 2D decorative layer, while the penguin remains the only 3D character.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

## Build

```bash
npm run build
```

Keep `public/models/penguin.glb` in place.
